IRCC Tracker Safe Windows v2.3（合并版）· 中文使用指南
=========================================================

本文件仅供阅读，不参与程序运行；即使乱码也不影响脚本工作。

【这是什么】
一个非官方、开源、隐私优先的 Windows 工具，用来查询 IRCC Application
Status Tracker 的申请状态，并在失败时给出脱敏诊断信息。

【重要提醒】
当前 IRCC 数据接口不稳定：登录通常能成功，但查询接口可能返回空列表或
HTTP 500。这多半是 IRCC 服务端的问题，本工具无法修复，也不保证一定
能取得状态。

【运行前准备】
1. 完整解压，不要直接在压缩包里双击运行；
2. 放到本机目录，避免 OneDrive / Dropbox 等同步目录；
3. 建议装 PowerShell 7（可选）；没有也能用系统自带的 5.1。

【使用步骤】
1. 双击 “点击运行IRCC查询.cmd”；
2. 按提示输入：
   - UCI：可输入纯数字或带连字符，例如 12345678 / 1234-5678 /
     1234567890 / 12-3456-7890；
   - Application Number：申请号；
   - Tracker 密码：输入时不显示，属正常现象；
3. 输入完成后画面会自动清屏，随后依次执行：
   登录 -> 账号申请列表预检 -> 申请详情查询；
4. 成功后会分两段显示：
   - Precheck (profile summary)：预检小结（找到几个申请、申请号是否
     属于当前账号）——仅供参考，不影响是否继续查询；
   - Application details：真正的申请状态结果。

【失败怎么办】
- 程序会显示脱敏诊断（出错阶段、HTTP 状态码、耗时等），并提示：
    按 R 手动重试一次；按 Q 退出。
- 程序不会自动重试；第二次失败后不再重试。
- 若诊断显示 IRCC 接口 HTTP 500 / 503：多为服务端故障，稍后再试。
- 若显示 403：可能被边缘防护拦截，建议关闭 VPN / 代理，用加拿大本地
  网络再试。
- 若登录报 “security reasons / NotAuthorizedException”：是 Cognito
  风控拦截，不是密码错误，换本地网络稍后再试。

【隐私说明】
- 不把凭据或 Token 写入磁盘，不保存结果或日志；
- 不使用第三方服务器 / 遥测，不下载或执行远程代码；
- 不关闭 TLS 证书验证，不高频重试，不修改你的申请资料。
- 提交错误截图前，请只保留红色错误与诊断区域，务必裁掉输入画面和
  个人资料。

【安全建议】
- 只查询本人或获授权管理的申请；
- 不要在公共 / 受感染 / 不受信任的电脑上运行；
- 不要分享你的凭据、Token、UCI、申请号或响应正文。
