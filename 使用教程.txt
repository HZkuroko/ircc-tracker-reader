IRCC Tracker Safe（Windows）v2.4.1 合并·双域名版 —— 使用教程
=====================================================

【这是什么】
一个只在你自己电脑上运行的小工具，用来查询你本人的 IRCC 申请状态（Application Status Tracker）。
非官方工具，和 IRCC / 加拿大政府 / AWS 没有任何关系。只查你自己的账户。

【最重要的隐私说明】
- 密码、登录令牌、查询结果都只在内存里，程序一关就没了，绝不写入任何文件。
- 全程开启 TLS 证书验证，绝不关闭，也不会把你的数据发给任何第三方。
- 输入密码时屏幕不会显示任何字符（连星号都没有），这是正常的，输完直接按回车。

【怎么用】
1. 解压后，务必让 “点击运行IRCC查询.cmd” 和 “IRCC_Status_Check.ps1” 待在同一个文件夹里。
2. 双击 “点击运行IRCC查询.cmd”。
   （它会自动把窗口设为 UTF-8，并优先使用 PowerShell 7；没有的话就用系统自带的 Windows PowerShell。）
3. 按提示依次输入：
   - UCI：8 位或 10 位数字，可以带横杠，程序会自动去掉横杠。
   - Application Number：你的申请号。
   - Tracker 密码：输入时看不到字符，属正常，输完按回车。
4. 稍等片刻，结果会显示在窗口里，分两部分：
   - Precheck（profile summary）：预检，仅供参考，不会因为它失败就不查详情。
   - Application details：申请详情，这才是权威结果。

【v2.4 新增了什么】
1. 登录报错更清楚：会区分“被风控拦截（不代表密码错）/需要重置密码/账号未激活/尝试太多次”等，并给出建议。
2. 更抗 IRCC 改版：详情字段换了名字也能尽量识别。
3. 自动补全证书链：修好了之前那个 “The SSL connection could not be established” 的报错。
4. 双域名自动切换：先试 A 域名，失败自动试 B 域名，不用你手动改。
   - A（默认）：tracker-suivi（入籍 citizenship tracker）
   - B（备用）：ircc-tracker-suivi（移民 application status tracker）
   - 如果你查的是移民/PR，想让 B 先试：用记事本打开 .ps1，把顶部 $Endpoints 里 A、B 两段顺序对调即可。

【常见报错怎么办】
- 显示 HTTP 500 / 502 / 503：IRCC 服务器自己在故障，你这边改不了，过几小时再试。
- 显示 HTTP 403：被 IRCC 的防护拦了。尽量用加拿大本地网络、关掉 VPN/代理再试。
- 登录提示 “security reasons”：是 Cognito 风控，不一定是密码错，别反复重试，晚点用官网。
- 提示脚本无法运行：.cmd 已自动加了 -ExecutionPolicy Bypass，正常双击即可；
  若仍不行，可右键 .cmd 选择“以管理员身份运行”。

【安全提醒】
- 截图或发报错给别人前，务必先遮住 UCI、申请号、姓名、生日、地址、邮箱、电话等信息。
- 不要把原始输出发到 GitHub Issue 或任何公开的地方。
- 请手动、低频查询，不要用它高频刷新。

祝顺利。
